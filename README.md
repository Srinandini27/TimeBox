# TimeBox - AI-Powered Daily Planner

## Description
Smart daily planner that uses OpenAI to optimize your schedule based on availability and task list.

## Features
- Input tasks and time window
- AI-generated time-blocked schedule
- Sync-ready with Google Calendar

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- AI: OpenAI API
- Calendar API: (Mock) Google Calendar

## Setup
1. Clone repo
2. Configure `.env` with your OpenAI key
3. Run backend: `node server/index.js`
4. Run frontend: `npm start` in client/
